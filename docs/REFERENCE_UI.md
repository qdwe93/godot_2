## 1. 게임 화면

### 1-1. 화면 방향은 **바꾸지 않는다**

레퍼런스는 세로(포트레이트)로 찍혀 있지만, 사용자가 명시했다 —
**"게임화면 방향을 바꾸라는건 아니야. 가로 세로 말이야."**

우리는 가로(1280x720 기준, 기기 화면비에 따라 확장)를 유지한다.
아래 관찰들은 전부 **방향과 무관한 부분**만 가져온 것이다.

레이아웃을 옮겨 볼 때 이 점만 감안하면 된다 — 레퍼런스에서 세로로 넉넉하던
공간(HUD 상단, 레벨업 카드 높이)이 가로에서는 빡빡하고, 반대로 좌우는 여유가 있다.
레벨업 카드 3장을 가로로 늘어놓는 것은 오히려 가로 화면이 유리하다.

### 1-2. HUD 배치

| 위치 | 내용 | 우리와의 차이 |
|---|---|---|
| 좌상단 | 일시정지 버튼 (큰 사각 아이콘) | **우리에겐 없다** |
| 상단 중앙 | 타이머 `00:28` — 아주 크고 흰 외곽선 | 우리는 우상단에 작게 |
| 우상단 | 코인 `0` / 처치 `42` — 아이콘 + 검은 알약 배경 | 코인 개념 자체가 없다 |
| 그 아래 | **화면 전체 폭 경험치 바**, 왼쪽에 `LV.3` 탭 | 우리는 좌상단에 짧은 바 2개 |

체력은 상단 바가 아니라 **캐릭터 바로 아래 작은 바**로 붙어 있다.
우리는 좌상단 HP 바 + 저체력 시 빨간 깜빡임이다.

### 1-3. 캐릭터 크기 — 지금 우리와 비슷하다

레퍼런스의 주인공과 좀비는 **화면 폭의 5% 안팎**이다. 적이 20마리 넘게 보여도
답답하지 않다.

우리는 M16에서 주인공 72px(1600 폭 기준 **4.5%**), 적 60px(3.8%)로 키웠다.
**거의 같은 비율이다.** 3배 확대는 방향이 맞았다는 뜻이고, 더 키울 이유는 없어 보인다.

다만 레퍼런스는 세로라 **세로 방향으로** 보이는 거리가 길다. 가로인 우리는
위아래로 좁으므로 적이 위/아래에서 더 갑자기 나타난다 — 지금도 그렇고, 바뀌는 건 없다.

### 1-4. 조이스틱이 고정 위치다

레퍼런스는 하단 중앙에 **항상 같은 자리에 그려진 큰 원형 링 + 어두운 노브**다.
우리는 화면 아무 데나 짚으면 생기는 **떠다니는** 방식이다 (M13).

둘 다 흔한 방식이고 우열이 있는 건 아니다. 다만 고정식은 "어디를 눌러야 하는지"가
눈에 보인다는 장점이 있다. 사용자가 M14에서 "조이스틱 감도는 일단 넘어갈 수 있는
정도"라고 했으니 나중에 다시 물어볼 것.

### 1-5. 그 밖에

- 바닥이 **밝은 회보라 큰 격자** + 흰 필드 경계선. 화면 밖으로 도로·횡단보도 같은
  실제 배경 아트가 이어진다. 우리 격자(#1E1E26, 근검정 위)보다 훨씬 밝다
- 젬이 초록 다이아몬드로 화면에 흩어져 있다. **개수가 우리보다 훨씬 적다** —
  바로 바로 주워지고 있다는 뜻 (우리는 최대 254개까지 쌓였다, STATUS 이슈 13)
- 피해 숫자가 흰 외곽선으로 뜬다 (`15`). **우리에겐 없다**
- 획득 대기 중인 무기/아이템이 주인공 주위에 떠 있다

## 2. 레벨업 화면

우리 것과 **구조가 다르다.** 우리는 가로 버튼 3줄이고, 레퍼런스는 카드 3장이다.

### 2-1. 구성 요소 (위에서 아래로)

1. **색종이 파티클** — 배경 위로 흩날린다. 레벨업이 보상처럼 느껴지게 하는 장치
2. **"스킬 선택" 리본 배너** — 노란 바탕에 양옆 화살표 장식
3. **보유 스킬 슬롯 바 2줄** ← 이게 제일 큰 차이다
   - 왼쪽 묶음: 무기 슬롯 6칸 (첫 칸에 이미 가진 무기 아이콘)
   - 오른쪽 묶음: 패시브 슬롯 6칸
   - 양 끝에 분류 아이콘
   - **지금 내 빌드가 어디까지 찼는지가 한눈에 보인다**
4. **카드 3장** (세로로 길쭉)
   - 상단: 노란 제목 탭 (`화염병` / `드릴샷` / `축구공`) + 우측 `New!` 리본
   - 중앙: 큰 아이콘
   - 아래: 설명 한 줄 (`화염병 2개 투척`)
   - 하단: **별 5개 등급** — 채워진 별 수가 현재 레벨
5. 하단 안내문 `배울 스킬을 선택하세요`

### 2-2. 우리 미처리 항목과 정확히 겹치는 것

STATUS 의 "레벨업 버튼에 현재 레벨 표시 (`get_level()`은 이미 있는데 UI가 안 씀)"
가 레퍼런스에서는 **별 등급**으로 해결돼 있다. `New!` 리본은 미획득 항목 표시다.

슬롯 바는 우리에게 없는 개념인데, 업그레이드가 39개까지 쌓이는 지금
"내가 뭘 갖고 있더라"를 보여줄 수단이 전혀 없다는 문제와 맞닿는다.

`tools/check_sprite_luminance.py` 의 `BACKGROUND` 가 통째로 달라지고,
**어두운 요소(투사체·젬)가 전부 대비 미달이 된다.** 스프라이트 색을 다시 잡아야 한다.
