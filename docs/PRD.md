# PRD — 제품 정의

## 무엇을 만드는가

**탕탕특공대(Survivor.io) 스타일의 2D 탑다운 서바이버 게임.** Godot 4.7.1 + GDScript.

플레이어는 이동만 조작하고 공격은 자동으로 나간다. 몰려오는 적을 처치해 경험치를 모으고, 레벨업마다 업그레이드를 골라 빌드를 쌓아 올린다. 시간이 갈수록 적이 강해지고, 죽으면 끝난다.

## 왜 만드는가

**AI 협업으로 게임을 만드는 과정 자체를 검증하고 기록하는 것이 목적이다.** 상용 출시가 아니다. 따라서 우선순위는 이렇다:

1. 각 단계마다 **실제로 실행되는 결과물**이 남을 것
2. 판단 근거와 시행착오가 **빠짐없이 문서로** 남을 것
3. 게임의 재미와 완성도 (위 두 개를 만족한 다음)

부수적으로 사용자가 Godot 게임 개발 방식을 익히는 목적도 있다. 그래서 문서는 GDScript 문법이 아니라 **엔진 개념·구조·제약조건**을 설명한다.

## 핵심 게임 루프

```
이동(WASD) → 자동 공격 → 적 처치 → 경험치 젬 드랍 → 수집 → 레벨업
   → 업그레이드 3택 → 더 강해짐 → 웨이브가 더 강해짐 → 반복 → 사망 or 생존
```

이 루프가 성립하려면 최소한 다음이 필요하다: 이동(M1), 적(M2), 공격(M3), 피해(M4), 성장(M5·M6), 압박(M7), 정보 표시(M8).

## 범위 안 (In Scope)

| 기능 | 마일스톤 |
|---|---|
| WASD 8방향 이동 | M1 |
| 적 스폰 및 플레이어 추적 | M2 |
| 가장 가까운 적 자동 조준 및 투사체 공격 | M3 |
| HP, 피격 판정, 무적시간, 게임오버 | M4 |
| 경험치 젬, 레벨업, 업그레이드 3택 UI | M5 |
| 무기 3종 이상 + 패시브 3종 이상 | M6 |
| 시간 기반 난이도 상승 + 보스 1종 | M7 |
| HUD(HP·경험치·타이머·킬수), 타이틀/게임오버 화면 | M8 |
| 타격 이펙트, 화면 흔들림, 사운드, 아트 교체 | M9 |
| 수치 밸런싱 | M10 |

## 범위 밖 (Out of Scope)

명시적으로 **만들지 않는다.** 나중에 원하면 마일스톤을 추가한다.

- 멀티플레이 / 온라인 기능
- 세이브·로드, 메타 진행(영구 강화), 상점, 재화
- 모바일 빌드 및 터치 조작 (Windows 데스크톱 전용)
- 스토리, 컷신, 대사
- 다국어 지원 (UI는 한국어)
- Steam 등 플랫폼 연동, 업적
- 3D

## 타깃 사양

| 항목 | 값 |
|---|---|
| 플랫폼 | Windows 데스크톱 |
| 조작 | 키보드 WASD (게임패드는 범위 밖) |
| 해상도 | 1280×720 창 모드 |
| 렌더러 | gl_compatibility (구형 GPU 호환성 우선, 2D에는 성능 충분) |
| 1회 플레이 시간 | 10~15분 목표 |

## 성공 기준

- 시작부터 사망까지 **끊기지 않고 한 판이 돌아간다**
- 레벨업 선택이 실제로 플레이 감각을 바꾼다 (선택이 의미 있음)
- 후반부에 적이 화면을 가득 채워도 프레임이 무너지지 않는다 (목표 60fps)
- 새 세션의 AI가 `docs/STATUS.md`만 읽고 작업을 이어받을 수 있다
